A Python-based AI voice agent that listens to voice commands, converts speech to text, provides AI-powered responses using Ollama/Llama 3.2, and performs controlled computer automation through predefined commands.

Features:
 Voice input
 Local LLM with Ollama + Llama 3.2
 Text-to-speech responses
 Website opening/search
 Controlled application automation
 Predefined commands for safer system access

Tech Stack
Python | SoundDevice | SpeechRecognition | Ollama | Llama 3.2
